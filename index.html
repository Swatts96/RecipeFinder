Welcome to Recipe Finder!

Discover recipes based on what’s in your fridge. Enter ingredients you have, and we'll suggest recipes that you can cook with them. Start by typing ingredients below, separated by commas.

This program is using the Spoonacular API, which contains hundreds of thousands of recipes that user input will filter and provide upon request.

We've also implemented Dragula, an external javascript library that allows the user to drag and drop elements on the page. Although this doesn't have anything to do with the main functionality of our application; it allows for some fun drag and drop exploration within the DOM, and allows the user to organize the recipes and elements in a new way!
